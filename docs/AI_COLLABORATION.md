# AI 协作约定

> 文档导航：[README.md](README.md)

AI 是结对教练，不是代写器。默认协作顺序如下：

1. 先写清目标、预期行为、实际行为、最小复现和已经尝试过的办法。
2. 需要代码时先要提示，不要先要完整答案。
3. 拿到提示后先预测结果，再运行代码。
4. 通过测试后，请 AI 做一次代码审查，重点检查边界、命名、重复和测试缺口。
5. 最后用自己的话解释：为什么这样改，哪里可能仍然失败。

## 提示层级

- 第 1 层：指出相关概念，不提供代码。
- 第 2 层：给出步骤或伪代码。
- 第 3 层：给出局部代码片段。
- 第 4 层：完整参考实现，只在已经尝试并完成复盘后使用。

## 高质量提问模板

```text
目标：
预期行为：
实际行为：
最小复现：
我已经尝试：
当前卡点：
我希望得到：第 1/2/3 层提示
```

## AI 代码审查模板

```text
请只审查，不重写。按严重程度列出：
1. 正确性和边界问题
2. 测试缺口
3. 可读性和结构问题
4. 可以保留的现有设计
每条都指出具体文件和行号。
```
