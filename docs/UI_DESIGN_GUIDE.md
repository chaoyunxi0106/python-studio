## 1. 指南目的

本指南是 [FRONTEND_PRD.md](FRONTEND_PRD.md) 的视觉执行补充，用于回答：

1. 页面应该怎样排布，模块之间如何建立层级。
2. 暗色工程工具风格如何保持统一、安静和可信。
3. 如何把参考设计网站的布局与交互规律转译为 Python Studio 自己的规则。
4. 新增页面、组件或 AI 功能时，如何避免视觉熵增。

指南只提炼规律，不复制任何网站的品牌资产、插画、配色或页面结构。

参考来源：

- [vibeui.top](https://vibeui.top/)：设计条目组织、网格、卡片、筛选和响应式展示方式。
- 附件图片：深色空间、玻璃卡片、细线分层、数据面板和关系图的视觉组合。
- Claude Overview 类公开设计：编辑式留白、环形场景构图、低噪声卡片和 constellation 关系图。参考网页快照不随项目分发，避免引入第三方品牌资产。
- [E-Ink / Paper](https://vibeui.top/extra/uiuxskillProMax/generated/56-e-ink-paper/DESIGN.md)：纸张、墨色、哑光表面、纸纹和克制动效。
- Notion 公开设计说明：暖中性色、发丝边界、单一强调色和低存在感阴影。
- Vercel 公开设计说明：阴影代替边框、等宽技术标签、精确焦点环和结构纪律。
- 其他条目仅用于比较不同设计语言的适用边界，不直接照搬品牌视觉。

## 2. 设计定位

Python Studio 是学习工具，不是营销落地页。

视觉目标：

- 安静：长时间阅读和编码不疲劳。
- 精确：状态、路径、测试结果和 AI 证据容易扫描。
- 可信：重要操作有清楚的层级和反馈。
- 克制：不靠渐变、光斑、超大标题或装饰性卡片制造吸引力。
- 一致：同一动作、同一状态和同一数据类型始终使用相同表达。

一句话方向：

> 深色工程工作台，加上编辑器式的排版纪律和少量高质量交互反馈。

- 16px 以上装饰性大圆角。
- 营销型 Hero、超大标题、整屏宣传文案。
- 大面积浅米色、米白或单色系主题。

## 4. 页面布局原则

### 4.1 三层外壳

```text
Rail 左栏
  课程与模式
  学习统计
  主导航
  路线或知识图

Stage 内容舞台
  页头
  二级导航
  当前任务或数据面板

Overlay 浮层
  悬浮伴学
  确认框
  全屏路线
```

尺寸建议：

| 区域 | 宽度或尺寸 |
| --- | --- |
| 左栏 | 280 至 300px |
| 主内容 | `minmax(0, 1fr)` |
| 阅读型页面 | 最大 1180px |
| 表单 | 最大 760px |
| 浮层对话 | 360 至 400px |
| 触控目标 | 最小 40px，桌面图标按钮可 32 至 36px |

### 4.2 网格与间距

统一使用 4px 基础步进：

```text
4 / 8 / 12 / 16 / 24 / 32 / 48
```

规则：

- 同组元素用 8 或 12px。
- 面板内间距用 16 或 24px。
- 页面区块之间用 24 或 32px。
- 不使用 10px、18px、26px 等无体系间距。
- 固定工具栏、图标按钮、图表面板和计数器不得因内容变化而抖动。

### 4.3 降低卡片嵌套

优先级：

```text
页面带
  > 面板
  > 分组
  > 单条重复项
```

- 页面区块使用全宽带或普通面板，不做“大卡片里再套卡片”。
- 重复条目才使用独立卡片。
- 同一屏内不要出现三层以上同心边框。
- 分组优先使用留白、发丝线和小标题，不增加新边框。

### 4.4 信息密度

- 首屏优先显示当前任务和下一步动作。
- 标题、状态、操作按钮处于同一扫描带。
- 路径、测试名、函数名和计数使用等宽字体。
- 次要说明可以折叠，但不能把主要操作藏进折叠区。
- 长列表默认显示 5 至 10 条，并提供清楚的浏览入口。

## 5. 视觉语言

### 5.1 色彩

保持现有暗色工作台方向，并降低蓝灰单一色调带来的“通用 SaaS 暗色模板感”。

建议设计令牌：

```css
:root {
  --bg: #0b0d10;
  --bg-deep: #07090b;
  --rail: #0e1116;

  --surface-1: #13161b;
  --surface-2: #191e25;
  --surface-3: #222831;
  --inset: #090b0e;

  --text: #eef1f4;
  --text-muted: #a5adb8;
  --text-subtle: #798392;

  --border: #252b34;
  --border-strong: #36404c;

  --accent: #5f82f5;
  --accent-strong: #8da4ff;
  --accent-soft: rgba(95, 130, 245, 0.14);
  --accent-line: rgba(95, 130, 245, 0.42);

  --success: #4ca66a;
  --warning: #d5a344;
  --danger: #e86f69;
}
```

语义约束：

| 颜色 | 只用于 |
| --- | --- |
| 蓝色 | 选中、主操作、链接、焦点 |
| 绿色 | 通过、完成、正向趋势 |
| 黄色 | 待完成、需要注意、缓存或样本不足 |
| 红色 | 失败、破坏性操作、错误 |

禁止：

- 使用蓝色表达成功或失败。
- 同一页面出现多个竞争性强调色。
- 用大面积渐变表达主要功能。
- 用低对比浅灰承载关键说明。

### 5.2 边界与阴影

参考 Vercel 的“阴影代替边框”思路，但在本项目中使用混合规则：

```css
border: 1px solid var(--border);
box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.035);
```

规则：

- 普通面板用发丝边框和顶部内高光。
- 浮层和弹层可以使用一层柔和阴影。
- 不使用大面积悬浮投影模拟“卡片漂浮”。
- 选中态同时使用边框、背景和文字变化，不只改变阴影。

### 5.3 圆角

参考站点常使用 16 至 28px 大圆角，本项目不跟随。

```text
小控件：4px
按钮和输入框：6px
卡片和面板：8px
状态胶囊：999px
```

图标按钮保持正方形或近正方形，不用大圆角包裹整块内容。

## 6. 字体与排版

### 6.1 字族

```css
--font-sans:
  -apple-system, BlinkMacSystemFont, "Segoe UI",
  "Microsoft YaHei", system-ui, sans-serif;

--font-mono:
  "Cascadia Code", "JetBrains Mono", Consolas,
  "SFMono-Regular", monospace;
```

规则：

- 中文正文使用系统无衬线字体。
- 路径、函数名、测试名、命令、计数使用等宽字体。
- 不引入网络字体，保持本地优先和离线可用。
- 不使用负字距，字距统一为 0。

### 6.2 字号层级

| 角色 | 字号 | 行高 | 字重 |
| --- | --- | --- | --- |
| 页面标题 | 26 至 28px | 1.25 | 700 |
| 区块标题 | 20 至 22px | 1.3 | 700 |
| 面板标题 | 16px | 1.4 | 700 |
| 正文 | 15px | 1.7 | 400 |
| 次要信息 | 13px | 1.6 | 400 至 600 |
| 标签与计数 | 12px | 1.4 | 600 至 700 |

不要在仪表盘、侧栏和卡片里使用 32px 以上标题。

### 6.3 内容排版

- 段落最大宽度 760px 左右。
- 代码块允许横向滚动，不能挤压整个页面。
- 行内代码使用 `--surface-3` 背景和 `--accent-strong` 文字。
- 提示、错误和结果区使用左边界语义色，不再套额外卡片。
- 路径和错误信息允许 `overflow-wrap: anywhere`。

## 7. 组件规范

### 7.1 按钮

| 类型 | 使用场景 |
| --- | --- |
| Primary | 一个面板只保留一个主操作 |
| Secondary | 辅助动作、刷新、返回 |
| Icon | 刷新、折叠、复制、全屏、关闭 |
| Micro | 条目级小动作、状态更新 |
| Danger | 删除、恢复、清理等破坏性动作 |

交互要求：

- 图标按钮必须有 `aria-label` 和 tooltip。
- 进行中状态禁用按钮并替换标签。
- 破坏性动作必须再次确认。
- 图标保持 14 至 16px，描边 1.75 至 2px。
- 不把清楚动作只做成没有文字的装饰图标。

### 7.2 导航与页签

- 主导航保持 5 项，不再增加顶层入口。
- 二级页签使用底部 2px 指示线。
- 选中态使用文字加线，不额外增加胶囊背景。
- 移动端页签横向滚动，不换行成多行。

### 7.3 面板

面板结构固定：

```text
眉标
标题
说明或计数
右侧动作
发丝分隔线
内容
```

面板中只有一个主要滚动区域。不要让每个子区域都独立滚动。

### 7.4 状态胶囊

- 通过：绿色。
- 待完成：黄色。
- 失败：红色。
- 来源：蓝色或中性色。
- 计数：中性色。

胶囊只用于短状态，不承载段落。

### 7.5 表单

- Label 在输入框上方。
- 输入框最小高度 38px。
- 输入框宽度跟随容器，不固定像素。
- 错误信息贴近字段，不只显示在页面底部。
- 设置页保持两列，窄屏改为单列。
- 密钥输入永不在页面回显。

### 7.6 空状态

统一句式：

```text
为什么为空
下一步去哪里产生内容
```

空状态不使用插画，不使用大圆角容器。

## 8. 页面级布局

### 8.1 练习页

推荐结构：

```text
关卡头：标题 / 状态 / 时间 / 刷新
模块进度
文件位置条
作答 / 讲义 / 协作页签
双栏工作区
  左：题目说明
  右：运行面板
当前关卡记录
```

规则：

- 桌面端双栏比例约 `1.45 : 0.8`。
- 运行面板在桌面端可粘滞，窄屏改为普通流。
- 代码、输出和结果区保持稳定高度，避免加载时跳动。
- 文件路径、模块、关卡和来源显示在同一位置。

### 8.2 档案页

推荐结构：

```text
页头
总览 / 诊断 / 补练 / 维护
指标带
趋势
最近运行
记录与折叠详情
```

数据展示优先：

- 数字大于图表。
- 趋势图只表达通过、失败和时间。
- 列表显示状态、时间、耗时、模块和知识点。
- 维护动作与学习数据分开，避免误触。

### 8.3 伴学页

结构：

```text
页头
工具条
隐私说明
会话工具条
已载入题目胶囊
消息列表
输入区
```

规则：

- 用户消息靠右，助手消息靠左。
- 助手 Markdown 需要保持安全渲染。
- 已载入题目始终可见，可逐条移除。
- 悬浮伴学与页面伴学复用同一消息组件和 API。

### 8.4 工坊页

桌面端：

```text
左：SVG 知识图
右：创造式对话与节点详情
```

窄屏：

```text
知识图
对话
节点详情
```

规则：

- SVG 图和面板使用相同边框和背景体系。
- 节点颜色只表达节点类型，不使用渐变。
- 节点标签必须在图内可见，过长时截断并提供详情。

### 8.5 设置页

- 模型设置和平台设置分页。
- 表单最大宽度 760px。
- 测试连接结果紧贴动作区。
- 危险操作和普通保存分开。

## 9. 动效

```css
:root {
  --dur-fast: 120ms;
  --dur-base: 160ms;
  --ease-out: cubic-bezier(0.22, 1, 0.36, 1);
}
```

只用于：

- 页签指示线。
- 抽屉展开。
- 按钮 hover。
- 状态切换。
- 浮层出现。

禁止：

- 无意义的持续动画。
- 装饰性漂浮。
- 数据加载时整页闪烁。
- 与 `prefers-reduced-motion` 冲突。

## 10. 响应式

保持现有断点：

```text
1180 / 1080 / 900 / 760 / 520
```

| 宽度 | 规则 |
| --- | --- |
| 1180 以下 | 双栏改单栏，左栏收窄 |
| 900 以下 | 左栏变抽屉并默认隐藏 |
| 760 以下 | 页头、工具条和表单改单列 |
| 520 以下 | 指标和操作进一步紧凑，避免横向滚动 |

检查项：

- 390 / 768 / 1024 / 1440 四档无横向滚动。
- 按钮文字不换行挤压图标。
- 路径和错误信息不撑破容器。
- 长中文标题不覆盖状态和操作。

## 11. 无障碍

- 正文对比度达到 WCAG AA。
- 焦点环清晰，颜色与背景有足够对比。
- 所有图标按钮有可读标签。
- 状态变化通过 `aria-live` 通知。
- 键盘可完成主导航、页签、运行和提问。
- Esc 关闭菜单和浮层。
- 所有触控目标最小 40px。

## 12. 视觉验收清单

每个新页面或新组件提交前检查：

1. 是否只有一个主操作。
2. 是否使用了统一的 4px 间距体系。
3. 是否出现了嵌套卡片。
4. 圆角是否超过 8px，除胶囊外。
5. 是否引入渐变、光斑或无意义装饰。
6. 状态颜色是否符合语义。
7. 中文长文本是否溢出。
8. 键盘焦点是否清楚。
9. 390px 宽度是否可用。
10. 空状态、加载、错误和成功状态是否完整。
11. 路径、函数名和测试名是否使用等宽字体。
12. 是否与 `FRONTEND_PRD.md` 的信息架构一致。

1. 缩减设计令牌中的无序颜色。
2. 统一 4px 间距和 4 / 6 / 8px 圆角。

4. 统一按钮、页签、胶囊、空状态和表单。
5. 优化练习页运行区和记录区。
6. 优化档案页指标、趋势和列表。
7. 优化伴学消息与上下文胶囊。
8. 优化工坊图谱与节点详情。
9. 在所有断点做视觉和键盘验收。

## 15. 综合视觉方案：暮色玻璃纸工作台

本章是 1.1 版本的补充方案，目标是在现有深色工具感上增加层次、空间和阅读温度，而不是把平台改成展示型网页。

### 15.1 核心命题

```text
工作区：深蓝黑空间 + 低对比网格 + 薄雾
工具层：磨砂玻璃卡片 + 细线边界 + 内部高光
阅读层：暖白纸张 + 墨色文字 + 轻度纸纹
关系图：星座节点 + 细连接线 + 低饱和光晕
```

使用原则：

- 玻璃用于工具、导航、状态、对话和浮层。
- 纸张用于题目说明、讲义、诊断解释和长文本阅读。
- 同一屏最多出现 1 个主要纸张阅读面。
- 关系图只使用低饱和节点和细线，不使用霓虹描边和大面积发光。
- 背景可以有空间感，但不能出现独立光斑、装饰球或无意义渐变。

### 15.2 材质层级

| 材质 | 用途 | 不适用 |
| --- | --- | --- |
| Graphite | 页面底色和左栏 | 承载长文本 |
| Glass | 工具卡片、运行面板、聊天、浮层 | 长文章正文 |
| Paper | 题目说明、讲义、诊断报告 | 高频工具操作 |
| Grid | 工作台背景、关系图 | 正文区域 |
| Ink | 纸张上的高对比文字和线稿 | 全局亮色主题 |

### 15.3 Glass 规范

推荐变量：

```css
:root {
  --space-top: #0b1730;
  --space-mid: #07101f;
  --space-bottom: #050912;

  --glass-bg: rgba(18, 31, 54, 0.68);
  --glass-bg-strong: rgba(20, 35, 61, 0.82);
  --glass-border: rgba(148, 181, 230, 0.18);
  --glass-border-strong: rgba(173, 202, 244, 0.28);
  --glass-top: rgba(255, 255, 255, 0.12);
  --glass-shadow: 0 22px 60px rgba(0, 0, 0, 0.34);
}
```

Glass 卡片结构：

```css
.glass-card {
  background: var(--glass-bg);
  border: 1px solid var(--glass-border);
  border-radius: 10px;
  box-shadow:
    inset 0 1px 0 var(--glass-top),
    var(--glass-shadow);
  backdrop-filter: blur(20px) saturate(118%);
  -webkit-backdrop-filter: blur(20px) saturate(118%);
}
```

约束：

- 玻璃卡片只覆盖内容区域，不让整个页面都使用 `backdrop-filter`。
- 相邻玻璃卡片保持 12 至 16px 间距。
- 边框必须足够可视，不能让卡片边界完全消失。
- 文本区域使用实色底或高不透明度玻璃，避免文字浮在背景上。
- `backdrop-filter` 必须提供不支持时的实色回退。

### 15.4 Paper 规范

从 E-Ink / Paper 提炼到本项目时，不改变全局暗色工作台，而是增加“纸质阅读面”。

推荐变量：

```css
:root {
  --paper: #f7f5ef;
  --paper-raised: #fffdf8;
  --paper-edge: #ded7ca;
  --paper-ink: #1a1a1a;
  --paper-pencil: #4a4a4a;
  --paper-muted: #777169;
  --paper-highlight: #fff200;
}
```

Paper 规则：

- 纸张使用暖白或灰白，不使用纯白大面积闪屏。
- 正文使用近黑墨色，标题和正文对比达到 WCAG AAA。
- 纸张边缘使用 1px 边线，不叠加多层投影。
- 纸纹只以低透明度噪声或细颗粒形式出现，不能影响文字锐度。
- 表格、测验、讲义和诊断结论优先使用纸张材质。
- 纸张内不使用玻璃模糊，避免文字边缘变软。

### 15.5 背景空间

背景允许使用一层非常克制的蓝黑空间：

```css
body {
  background:
    linear-gradient(180deg, var(--space-top) 0%, var(--space-mid) 44%, var(--space-bottom) 100%);
}
```

细则：

- 渐变只用于空间深度，不作为主角。
- 不增加独立圆形光斑、彩色雾团或 bokeh。
- 网格线条控制在 3% 至 7% 不透明度。
- 背景变化必须在 1000px 高度内保持低对比。

### 15.6 卡片布局

参考附件图片的三栏结构：

```text
左侧：导航和工具
中央：主任务和主数据
右侧：上下文、解释和关系图
```

桌面建议：

```css
dashboard-grid {
  grid-template-columns: minmax(220px, 0.8fr)
                         minmax(0, 1.45fr)
                         minmax(280px, 0.9fr);
  gap: 16px;
}
```

卡片层级：

```text
1 个主卡片
1 至 3 个辅助卡片
0 至 1 个关系图卡片
```

不要把所有内容都变成同尺寸卡片。主卡片面积应明显大于辅助卡片。

卡片内部顺序：

```text
标题
简短状态
主要数据或任务
次级操作
```

### 15.7 关系图美术

参考 Claude Overview 的 constellation 结构，将工坊图谱设计为低噪声关系图：

- 节点为 10 至 18px 的小圆或短圆角节点。
- 连接线为 1px，低对比蓝灰色。
- 节点使用低饱和填充和轻微外圈，不使用实心霓虹。
- 中心或当前节点使用柔和光环，不使用大面积发光。
- 边线不做复杂箭头，方向通过节点布局表达。
- 标签放在节点右侧或下方，最长 16 个中文字符。
- 节点悬浮时只做 1px 位移和描边增强。

推荐图区变量：

```css
--graph-line: rgba(138, 174, 230, 0.34);
--graph-node: rgba(96, 138, 214, 0.18);
--graph-node-border: rgba(151, 190, 246, 0.72);
--graph-glow: rgba(84, 139, 245, 0.22);
```

### 15.8 页面化应用

| 页面 | 主材质 | 重点 |
| --- | --- | --- |
| 练习 | Glass 工作区 + Paper 任务说明 | 左侧保持路线，中央阅读，右侧运行 |
| 档案 | Glass 指标 + Paper 诊断摘要 | 趋势和记录保持高信息密度 |
| 伴学 | Glass 对话 + Paper 引用块 | 消息气泡使用半透明深色层 |
| 工坊 | Graphite 图区 + Glass 侧栏 | 关系图低噪声，节点可被追踪 |
| 设置 | Glass 表单 + Paper 说明 | 密钥和危险操作保持清晰边界 |

### 15.9 动效

1. 卡片进入：`opacity 0 -> 1`，`translateY(4px) -> 0`，180ms。
2. 图节点出现：`scale 0.96 -> 1`，160ms。
3. 连线出现：从 0 到 1 的透明度，延迟不超过 80ms。
4. 卡片 hover：`translateY(-1px)`，边框亮度增加。
5. 当前节点：每 4 至 6 秒一次极轻微光环呼吸，幅度不超过 2px。

不采用：

- 大面积模糊移动。
- 持续明显的漂浮。
- 背景持续晃动。
- 节点连续抖动。
- 影响阅读的视差。

### 15.10 可访问性与性能

- `backdrop-filter` 必须提供实色回退。
- 玻璃层上的文字需使用高不透明度背景或阴影提高对比。
- 关系图不能仅依赖颜色区分节点类型，应保留节点标签或图例。
- 页面静止时不应持续运行昂贵动画。
- 移动端默认减少模糊层数量和阴影强度。
- 纸张面不使用模糊，确保文字清晰。
